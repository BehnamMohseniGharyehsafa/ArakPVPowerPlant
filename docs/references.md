# Verified scientific and technical references

Bibliographic details and selected model equations were checked against the following primary publisher, laboratory, project and official documentation pages on 1 November 2026. Standard text and copyrighted report figures are not reproduced. Publications support model choices; they do not validate this illustrative plant or its parameters.

1. **IEC 61724-1:2021.** *Photovoltaic system performance — Part 1: Monitoring*. IEC publication metadata identifies edition 2, published 21 July 2021. Used for terminology and monitoring principles; the full paid standard was not assessed and no monitoring-class compliance is claimed. [IEC catalogue](https://webstore.iec.ch/en/publication/65561).
2. **Sandia National Laboratories, PV Performance Modeling Collaborative.** *Performance Ratio*. Used for final/reference yield and conventional PR definitions. [Primary explanation](https://pvpmc.sandia.gov/modeling-guide/5-ac-system-output/pv-performance-metrics/performance-ratio/).
3. **Dobos, A. P. (2014).** *PVWatts Version 5 Manual*. NREL/TP-6A20-62641. [DOI 10.2172/1158421](https://doi.org/10.2172/1158421). The implemented baseline uses pvlib's documented v5 DC/inverter relationships. [pvlib DC](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.pvsystem.pvwatts_dc.html), [pvlib inverter](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.inverter.pvwatts.html), [Sandia PVWatts](https://pvpmc.sandia.gov/modeling-guide/2-dc-module-iv/point-value-models/pvwatts/). [PVWatts v8 API documentation](https://developer.nlr.gov/docs/solar/pvwatts/v8/) is an alternative tool reference; this repository neither calls that API nor claims to implement every v8 feature.
4. **De Soto, W., Klein, S. A. and Beckman, W. A. (2006).** *Improvement and validation of a model for photovoltaic array performance*. Solar Energy, 80(1), 78–88. [DOI 10.1016/j.solener.2005.06.010](https://doi.org/10.1016/j.solener.2005.06.010). Reference details and required parameters are given by the [pvlib De Soto documentation](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.pvsystem.calcparams_desoto.html). Used only with complete user-supplied parameters and provenance.
5. **Faiman, D. (2008).** *Assessing the outdoor operating temperature of photovoltaic modules*. Progress in Photovoltaics, 16(4), 307–315. [DOI 10.1002/pip.813](https://doi.org/10.1002/pip.813). [pvlib implementation and coefficient interpretation](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.temperature.faiman.html). Defaults represent module-temperature coefficients from a specific open-rack experiment, not site-calibrated cell-temperature coefficients.
6. **Mikofski, M., Darawali, R., Hamer, M., Neubert, A. and Newmiller, J. (2019).** *Bifacial Performance Modeling in Large Arrays*. 2019 IEEE 46th Photovoltaic Specialists Conference, 1282–1287. [DOI 10.1109/PVSC40753.2019.8980572](https://doi.org/10.1109/PVSC40753.2019.8980572). Bibliography and model assumptions are verified in the [pvlib infinite-sheds documentation](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.bifacial.infinite_sheds.get_irradiance.html).
7. **Kimber, A., Mitchell, L., Nogradi, S. and Wenger, H. (2006).** *The Effect of Soiling on Large Grid-Connected Photovoltaic Systems in California and the Southwest Region of the United States*. IEEE 4th World Conference on Photovoltaic Energy Conversion. [DOI 10.1109/WCPEC.2006.279690](https://doi.org/10.1109/WCPEC.2006.279690). The title, year and DOI, accumulation assumptions, manual wash resets and rainfall grace periods were checked against the [pvlib implementation documentation](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.soiling.kimber.html). Its regional coefficients are not adopted as validated Iranian parameters.
8. **IEA PVPS Task 13 (2024).** *Best practice guidelines for the use of economic and technical KPIs*. Report IEA-PVPS T13-28:2024. [Official report](https://iea-pvps.org/wp-content/uploads/2024/12/IEA-PVPS-T13-28-2024-REPORT-Technical-and-Economic-KPIs.pdf). Supports explicit technical/economic definitions and system boundaries; no invented standard clause is cited.
9. **IEA PVPS Task 13 (2026).** *Digitalisation and Digital Twins in Photovoltaic Systems*. Report IEA-PVPS T13-34:2026, February 2026. [Official publication page](https://iea-pvps.org/key-topics/t13-digitalisation-twins-pv-systems-2026/), [official PDF](https://iea-pvps.org/wp-content/uploads/2026/02/IEA-PVPS-T13-34-2026-REPORT-Digitalisation-Twins.pdf). Used to distinguish a simulation foundation from a twin continuously updated with operational measurements and to motivate traceable interoperable data.
10. **Climate.OneBuilding.Org.** *Climate/Weather Data Sources*. [Source/methodology page](https://climate.onebuilding.org/sources/default.html). The official source describes TMYx as typical meteorological data composed from multiple years, with provenance in the EPW comment fields. [Requested Arak archive](https://climate.onebuilding.org/WMO_Region_2_Asia/IRN_Iran/MK_Markazi/IRN_MK_Arak.407690_TMYx.zip). The application stores the actual original ZIP/EPW and checksums; it does not infer historical plant weather.

Additional implementation references:

* [pvlib EPW importer](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.iotools.read_epw.html): calendar coercion, metadata and timestamp interpretation.
* [pvlib NREL SPA](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.solarposition.spa_python.html): solar position implementation.
* [pvlib Hay-Davies](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.irradiance.haydavies.html): anisotropic sky transposition.
* [pvlib cell-from-module correction](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.temperature.sapm_cell_from_module.html): irradiance-scaled cell/module temperature difference.
* [SciPy MILP / HiGHS](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html): open-source binary repair selection. The cleaning dynamic programme is an explicit optimisation of the stated engineering objective, not a new empirical physical law.
* [NumPy Financial NPV](https://numpy.org/numpy-financial/latest/npv.html): time-zero cash convention.
